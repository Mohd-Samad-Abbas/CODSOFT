## 🛠️ Technologies Used
- **Language**: Python 3.x
- **Libraries**: pandas, numpy, matplotlib, seaborn, scikit-learn
- **Algorithms**: Logistic Regression, Decision Tree, Random Forest, SVM, Gradient Boosting, KNN
- **Techniques**: Feature Engineering, Cross-Validation, StandardScaler, Undersampling

---

## 📊 Key Results

### Task 1 — Titanic Survival Prediction
- Best Model: **Random Forest** (82.68% accuracy)
- Features used: Pclass, Sex, Age, Fare, FamilySize, Title

### Task 3 — Iris Flower Classification
- Best Model: **SVM** (96.67% accuracy)
- 3 Species: Iris-setosa, Iris-versicolor, Iris-virginica

### Task 5 — Credit Card Fraud Detection
- Best Model: **Random Forest** (99.89% accuracy)
- Handled severe class imbalance using undersampling
